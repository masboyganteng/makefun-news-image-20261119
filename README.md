A newspaper front page that sums up the world's news of **Thursday, 19 November 2026** in one image.

Top story: the U.S. and Iran strike each other again, and the fighting spreads across the Gulf. Also inside: GTA VI's global rollout, the Trump–Xi–Putin trilateral in Shenzhen, Hakeem Jeffries' historic House nomination, Voyager 1's light-day milestone, Cyclone Akvan, the EU's €45bn Ukraine loan, plus Nvidia, the Fed minutes, and India's SAFF Championship win over Pakistan.

`main.py` (Python 3.13, standard library only) copies the pre-rendered `entry.png` to `/output/entry.png` — deterministic, no network. `draw.py` is the local PIL generator that produced the image.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
